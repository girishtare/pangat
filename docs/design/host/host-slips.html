Slips

A small slip for each printed card, with that family's QR code and short code. Cut along the dashed lines and put one in each card.

Which slips

No contact number for the groom's side, so their slips have no "call us" line. Add it in Event settings.

Before you print

  • A4 paper, scale 100% (not "fit to page").
  • Print one sheet first and scan a QR code with your phone.
  • Thicker paper (100 gsm or more) holds up better in the card.
